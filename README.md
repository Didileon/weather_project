# weather_project

Приложение прогноза погоды с сохранением истории запросов.

Стек технологий:

Backend: Django + Django REST Framework

Frontend: React (create-react-app)

API: Open-Meteo.com

 База данных: SQLite (по умолчанию). Есть возможность переключения на PostgreSQL через Docker.

Docker: Полностью контейнеризированное приложение с помощью docker-compose

Возможности:
Поиск прогноза погоды по городу (латиницей)

Используется геокодинг Open-Meteo для получения координат

Отображение текущей температуры

Сохранение истории запросов в базе данных

Поддержка Docker (одна команда — и всё работает)
